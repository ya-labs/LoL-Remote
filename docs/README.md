- [Guia para IA](guia-de-documentacao-para-ia.md): leitura e atualização segura

## Fonte de verdade

- Produto e limites: `docs/visao-do-produto.md`.
- Arquitetura aprovada: `docs/arquitetura.md` e ADRs futuros.
- Sequência de entregas: `docs/roadmap.md`.
- Trabalho atual: GitHub Project #4, milestone e issue correspondente.
- Implementação: código e testes do repositório.

Quando houver divergência, a entrega real e a decisão aprovada mais recente
prevalecem. Atualize o documento desatualizado no mesmo bloco de trabalho.
